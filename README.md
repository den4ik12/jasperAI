# JasperAI

JasperAI - локальное приложение для генерации JasperReports-шаблонов (`.jrxml`) из HTML-макетов с помощью LLM. Поддерживаются DeepSeek и GigaChat.

## Что делает

1. Принимает HTML-макет документа.
2. Извлекает структуру элементов через LLM: текст, поля данных, прямоугольники, изображения и группировки.
3. Обогащает элементы координатами из браузерного рендера.
4. Масштабирует координаты под целевой формат страницы.
5. Группирует связанные блоки во фреймы и настраивает динамическое растяжение текста.
6. Генерирует готовый `.jrxml`.
7. Компилирует результат и при ошибках пытается исправить JRXML через LLM.
8. Может сформировать PDF-превью и варианты JSON-данных для проверки отчета.

## Запуск через CLI-агента

Пользователь запускает JasperAI не вручную через shell-скрипты, а через любой CLI-агент, которому можно передать инструкцию из `scripts/SKILL.md`.

Сначала запустите свой CLI-агент. Затем введите в него запрос в таком виде:

```text
scripts/SKILL.md запустить Jasper
```

Это не название конкретной CLI-команды. У разных пользователей CLI может называться по-разному. Важная часть - передать агенту файл `scripts/SKILL.md` и рядом написать действие, например `запустить Jasper`.

Примеры пользовательских запросов:

```text
scripts/SKILL.md запусти JasperAI
scripts/SKILL.md открой редактор печатных форм
scripts/SKILL.md подними приложение для генерации JRXML
```

Дальше процесс выглядит так:

1. CLI-агент читает `scripts/SKILL.md`.
2. Агент переходит в папку `scripts`.
3. Агент проверяет, есть ли `jasper_ai.jar`, `env`, Java и доступ к логам.
4. Если чего-то не хватает, агент задает пользователю вопросы.
5. Пользователь отвечает на вопросы агента в терминале.
6. Агент создает или обновляет нужные файлы, например `scripts/env`.
7. Агент запускает JasperAI.
8. После успешного запуска агент сообщает адрес приложения: `http://localhost:8080/`.

Если агент спрашивает провайдера, выберите один вариант:

```text
DeepSeek
GigaChat
```

Если агент спрашивает API-ключ, вставьте ключ выбранного провайдера в ответе CLI. Не добавляйте ключ в README, `application.properties` или другие файлы проекта.

Для остановки используйте тот же подход:

```text
scripts/SKILL.md остановить Jasper
```

CLI-агент сам выполнит нужный сценарий из `scripts/SKILL.md` и сообщит результат.

## UI

Главный интерфейс доступен по адресу `http://localhost:8080/`.

Перед открытием UI приложение должно быть запущено, а порт `8080` должен слушать процесс JasperAI.

Рабочий процесс:

1. Нажмите `Выбрать HTML-файл` и выберите HTML-макет с компьютера.
2. Выберите формат страницы: `A3`, `A4`, `A5`, `LETTER` или `LEGAL`.
3. Нажмите `Извлечь`, чтобы LLM построила структуру элементов.
4. При необходимости отредактируйте найденные элементы в интерфейсе.
5. Нажмите `Сгенерировать`, чтобы получить JRXML.
6. Используйте PDF-превью для быстрой визуальной проверки результата.

Отдельная страница `test-data.html` помогает сгенерировать варианты JSON-данных по готовому JRXML.

### Добавление HTML-макета

Дополнительная настройка больше не нужна: выберите нужный `.html` или `.htm` файл через кнопку `Выбрать HTML-файл` в правой панели редактора.
